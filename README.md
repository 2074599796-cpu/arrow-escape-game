# 一箭又一箭 · 飞剑问道

使用 Python 标准库 Tkinter 独立开发的箭头路径消除小游戏。视觉采用《剑来》题材启发的东方仙侠氛围，并保留作业要求的基础规则。白玉金纹飞剑根据用户提供的参考图通过 AIGC 制作为透明游戏素材，水墨山形、剑气和界面元素由代码绘制；项目没有直接嵌入参考原图，也不使用原游戏代码或关卡。

## 功能

- 开始界面、游戏界面、过关界面和失败界面完整；
- 四方向箭头与同行/同列路径检测；
- 上、下、左、右四方向白玉金纹飞剑图片，剑尖明确表示移动方向且没有圆形底座；
- 开始界面使用用户提供的《剑来》人物海报，并通过暗化延展适配横向窗口；
- “骊珠洞天、山水问剑、剑气长城、倒悬山、十四境”五境主题与水墨山河界面；
- 带加速、三道剑气拖尾和光点的飞出动画，以及带冲刺、火花、冲击环和回弹的碰撞反馈；
- 五个经过状态搜索验证的可解关卡，并支持已解锁关卡选择；
- 剩余飞剑、剑心、当前关卡、积分和计时实时显示；
- 过关后给出一至三星评价，并保存关卡解锁进度和最佳星级；
- 提示可安全飞出的飞剑，支持按钮或 `H` 键；
- 撤销上一次有效操作，恢复飞剑、剑心和积分，支持按钮或 `Ctrl+Z`；
- Windows 下带有飞出、碰撞和过关提示音；
- 关卡切换、失败重试、当前关卡重开和整局重玩；
- 12 项自动化单元测试覆盖核心规则、扩展功能与关卡可解性。

## 开发与运行环境

- Python 3.10 或更高版本（已在 Python 3.13 上验证）
- Windows 10/11（Tkinter 随官方 Python 安装）
- 无第三方依赖，无需安装 Pygame

## 运行方法

在项目目录打开 PowerShell：

```powershell
python main.py
```

也可以双击 `run_game.bat`。

## 游戏操作

1. 点击“执剑入局”。
2. 观察飞剑的剑尖朝向；若该方向直到棋盘边缘都没有其他飞剑，即可点击使其破阵飞出。
3. 点击被阻挡的飞剑会扣除一点剑心。
4. 清空当前棋盘进入下一关；三次失误后可重新挑战。
5. 点击“提示”或按 `H` 可高亮一支安全飞剑。
6. 点击“撤销”或按 `Ctrl+Z` 可撤销上一步；按 `R` 可重置当前关卡。
7. 从开始页进入“境界选择”，可重玩已经解锁的关卡。

## 测试

```powershell
python -m unittest discover -s tests -v
```

测试覆盖：无阻挡飞出、阻挡碰撞、边界处理、过关切换、失败判定、重新开始、提示、撤销、关卡选择、存档容错以及全部关卡可解性。

开发环境下还可以运行 `python tools/smoke_gui.py`，自动点击阻挡箭头并验证碰撞动画、回弹和失误次数。
